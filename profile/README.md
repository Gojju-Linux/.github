# Gojju Linux

**Linux, native on Apple Silicon.** Tangy, spicy, homemade.

Named after *tomato gojju*, the Karnataka dish. We are working on booting Linux on Apple's M4 Macs and building a distro around it.

**Status: early research. Nothing boots yet.**

Standing on the work of [Asahi Linux](https://asahilinux.org/), [m1n1](https://github.com/AsahiLinux/m1n1), Gravity Linux and [Omarchy-M4-Native](https://github.com/Kb2uka/Omarchy-M4-Native). Not affiliated with them or with Apple.
